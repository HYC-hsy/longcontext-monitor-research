# Historical visible-source projections

These are read-only backfills from already-ended real episodes that previously lacked a vetted public visible-content package. Each run directory contains `INDEX.json` and the recorded Task event stream and/or auxiliary event, transport, and memory streams that existed for that run. The compressed files are complete redacted/re-encoded streams of the named originals, with per-line original/public SHA-256 mappings. They are not raw HTTP bytes, and one stream must not be mistaken for an independent capture of another.

Read `task_events.jsonl.gz` for actual recorded Task request/response, selected action, and later Task-visible tool result. Read `pma_*` or `pos_*` for auxiliary-stage inputs, public outputs and recorded memory changes where those sources existed. `live_result.json.gz` provides the public terminal/evaluation record. `INDEX.json` states the source hashes, per-file redactions and absence of hidden-test/script export. A missing source file means it was not selected or not found; it must not be interpreted as a silent model decision.

Where the PMA-style trajectory and Task event originals both exist, `reminders.jsonl.gz` separately records each `should_inject` text and whether that exact text first appears in a later complete Task request with a visible response. Source step, request, response and action identities are included. A repeated appearance in later history is not counted as a new insertion. This is exact-text/timestamp linkage, **not** an independent delivery acknowledgment. The one unmatched historical reminder remains unmatched, not silently counted as delivered. PoS variants lack this PMA trajectory structure; their auxiliary and Task streams are provided, but reminder-to-request linkage remains unverified in the coverage matrix.

All private originals remain in their original local run directories. No model, Task, verifier, or evaluation was invoked by this export. Hidden reasoning, profiles, credentials, private endpoints, raw headers, verifier scripts and hidden test contents are excluded. Tool output may already have been truncated before capture; no unrecorded text is reconstructed.
