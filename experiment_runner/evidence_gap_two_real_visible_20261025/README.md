Read each run's `task_events.jsonl.gz` for the full captured Task request/response/action event stream, including tool call IDs and later Task-visible receipts. Read `pma_memory_payload.jsonl.gz` and `pma_gap_visible_transport.jsonl.gz` for actual Phase 1/Phase 2 visible inputs and public outputs, `pma_gap_cycle.jsonl.gz` and `pma_accepted.jsonl.gz` for write outcomes and formal gap views, `pma_trajectory_memory.json.gz` for the two-stage decisions, and `pma_memory.json.gz` for the final memory and source registry. `reminders.jsonl.gz` separately links recorded reminder text to a later complete Task request and response; exact text/timestamp matching is not an independent transport acknowledgment, and a reminder remaining only in history is not counted as a new insertion. `live_result.json.gz` records Task terminal and evaluation status. The public [evaluation index](EVALUATION.json) gives only safe native test counts and hashes, not hidden assertions.

Each per-run `INDEX.json` binds 11 selected original files to compressed public files, original/public SHA-256, source-line/public-line SHA-256 and redaction counts. The public JSON is re-serialized after masking; it is **not** raw HTTP or original source bytes. Original source IDs and hashes remain authoritative only in the unchanged private run. Hidden reasoning, credentials, private profiles/endpoints, headers, verifier script, test cases and hidden test output were not exported. Recorded Task-visible tool output may itself be truncated; this package does not reconstruct unseen bytes. The exporter selected all captured event rows from the listed sources, not a developer-chosen excerpt. No model, Task, or evaluator was invoked to produce this package.

Both runs reached `task_end`, each started native testing once, and the batch result lists no unstarted slot. The public evaluation status and counts can be audited, but hidden tests cannot be inspected or used to infer what the Task saw during execution.
