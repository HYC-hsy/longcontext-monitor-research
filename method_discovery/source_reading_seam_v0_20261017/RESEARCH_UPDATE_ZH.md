# 近邻筛选与监督机制候选：研究进展

日期：2026-10-17。状态：源码研究与假传输原型；没有新增真实模型、Task 或评价调用，没有证明任务效果提升。

## 当前判断

当前更值得研究的是：已经出现的要求和观察，怎样约束一个会影响后续行动的判断。历史 sampler 的 density 要求并未遗失；compressor 的局部探针也不能替代完整解码失败。此前 54 次输入视图诊断没有稳定获胜者，不能把删除分析或记忆本身当成答案。

PoS 已经有目标构建、belief 审核/替换和恢复。因此，重复这些模块不能直接成为我们的新贡献。下一步先区分：目标初读错误、证据范围扩张、正确状态在投递时失真，还是 Task 看到了正确状态仍采取不兼容行动。若 PoS 已解决某项，就删除为该项重复建设的理由。

## 本次筛出的近邻

1. **StateAuditor**：研究记忆变化后，回答仍隐含旧前提的问题。值得借鉴从状态到具体回答依赖的检查方向。但其引用/时间校验不验证语义替代关系，消融也不支持把主要收益归给这道校验。尚未核实作者实现和代码许可，所以暂不列为可直接复用代码的底座。[论文](https://arxiv.org/abs/2608.01619)
2. **Reflexion**：有 MIT 许可的反馈—修正实现，可参考错误反馈怎样进入下一次行动。其编程循环在内部测试通过时停止，弱测试仍可能让错误产物被接受；它不是我们证据范围问题的现成解法。[作者代码](https://github.com/noahshinn/reflexion/tree/218cf0ef1df84b05ce379dd4a8e47f17766733a0)
3. **ProCo**：用候选答案反推被遮蔽的条件，体现了改变检查运算而不只是要求更谨慎。公开代码有 Apache-2.0 许可。但其字符串近似停止规则不适合移植到接口约束：density 与 log-density 编辑距离为4、又有包含关系，会触发该规则。这是确定性迁移反例，不是该论文任务上的新实验。[作者代码](https://github.com/wzy6642/ProCo/blob/4aec09fcafe375a5029c80e7e5bf28a16b18aad6/code/prompt.py)
4. **Is Self-Repair a Silver Bullet?**：最值得借鉴的是实验分解，固定规范、程序、错误与修复模型，只改变反馈，再测实际修复。不能只评分建议写得好不好。作者仓库可读，但未核实可复用许可证，因此当前学习实验结构，不复制实现。[论文](https://arxiv.org/abs/2306.09896) · [作者仓库](https://github.com/theoxo/self-repair)

## 一个可运行、尚未被证明有效的候选

在原版 PMA 前加一次有限的依据重读：

1. 重读调用看到完整原任务、已认证的用户更新，以及普通窗口内的命令和工具结果；不看银行与独立的旧分析/工作记忆包装。
2. 它仅描述要求、观察范围与未决事项，不直接修改银行或指挥 Task。工具参数、代码注释和输出里仍可能有 Task 自己的解释，不能称为纯事实。
3. 重读结果仅进入原版 Phase 1。PMA 结合完整历史和既有记忆决定是否采纳、拒绝或缩小该解释，使用原来的记忆工具。
4. Phase 2 不额外注入重读结果，按原版流程使用实际更新后的银行。这样能检查银行是否真正发生了有益修订，避免一段新提醒掩盖仍然错误的记忆。
5. Task 的行动与结束决定不由这一步审批。辅助结果失败时明确记录并走普通 PMA 路径；这不算候选成功。

原型保留原版 PMA 的 BM25 默认设置、记忆 CRUD、两阶段调用和输出格式。复用了已审计的输入投影函数，没有新建图谱、判断状态机或来源坐标工具。

## 候选必须胜过的简单方案

同一执行入口准备了：普通PMA、隔离重读、可见旧银行/叙述的重读、原任务直接重放、完整来源包直接重放。额外调用数相同不代表token和延迟相同，必须分别报告。

如果直接重放一样好，删掉重读模型；如果重读正确但银行或建议仍错，停止继续优化抽取器；如果PoS已经修好银行但Task仍做错，转向动作后果与建议使用；如果改进只来自少发提醒而损害普通帮助，也不能宣称有效。

## 理论边界

可以借用带预测算法的评估要求：正确辅助要带来收益，错误辅助的损害也要测量。但现有任务没有已知代价、可信奖励和安全动作集合，不能直接借用其最坏情况保证。依赖维护算法只能维护已声明的关系，不能判断语义关系是否正确。

目前可机械保证的是信息从哪里进入、是否修改了存储、是否投递；解释是否成立、建议是否有用，仍需独立语义评估和真实Task对照。不能用同源判断的重复、引用存在或漂亮公式替代这些验证。
