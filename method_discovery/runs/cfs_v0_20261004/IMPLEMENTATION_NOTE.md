# CFS-v0 implementation and offline boundary

This candidate keeps the PATH/continuous single-Supervisor system prompt and seven tools unchanged. With `monitor_coarse_to_fine_surface=false` (or absent), the existing PATH recent-public-event window and WTV wake prose remain in place. With the flag true and EIS off, the old two displays are replaced by one bounded `Supervisory Situation` in ordinary provider-ready requests, including root reviews. CFS adds no wake, checker, model stage, test classifier, or completion gate.

The public-event reader advances through complete JSONL records only. The workspace sampler compares regular-file path/fingerprint facts without following symlinks and keeps an incomplete scan explicit. The display is at most 3400 characters; the corresponding `monitor/audit/cfs_deltas/<review>-<sequence>.json` retains full mechanical path and paired `code_run` lists with source locators. The rendered block is itself audited. The cursor is marked shown only after the provider request containing that active context successfully returns a model response, and committed at review end. Provider retries reuse the same active block and advance the cursor once on eventual success; failed recovery does not advance it, so a later review can show the interval again. No claim is made about whether the provider read a failed or timed-out request. Same-review requests without new Task events or path changes receive a short unchanged line; follow concurrency can refresh just the newly visible interval. A root handoff routes to a root review even if the ordinary review has not consumed its event.

`SPLIT_BOUNDARY_REPLAY.json` also forces the archived Kitex #117/#118 and Fyne #53/#54 call/result pairs onto adjacent observed-cursor intervals. The first surface has a call without an observed return; the second uses the same identity, current result locator, and historical public call locator/command. The printed `go test ./...` in Kitex remains raw command text, not a validation classification.

Known mechanical limits: metadata fingerprints can miss an edit that restores the same sampled metadata; changes between samples can be missed; a concurrent workspace writer means a scan is not a frozen review snapshot. Symlinks and `.git` are excluded. `code_run` rows are selected by new call/result facts in the displayed interval; call metadata may be looked up from complete earlier public events, but a result beyond the current visible cursor is never inferred. Conflicting repeated call arguments are retained as mechanical conflicts without choosing a semantic version. Unparseable results remain raw/unknown. The surface is excerpted; the full derived manifest and original public event remain available.
