# CFS-v0 implementation and offline boundary

This candidate keeps the PATH/continuous single-Supervisor system prompt and seven tools unchanged. With `monitor_coarse_to_fine_surface=false` (or absent), the existing PATH recent-public-event window and WTV wake prose remain in place. With the flag true and EIS off, the old two displays are replaced by one bounded `Supervisory Situation` in ordinary provider-ready requests, including root reviews. CFS adds no wake, checker, model stage, test classifier, or completion gate.

The public-event reader advances through complete JSONL records only. The workspace sampler compares regular-file path/fingerprint facts without following symlinks and keeps an incomplete scan explicit. The display is at most 3400 characters; the corresponding `monitor/audit/cfs_deltas/<review>-<sequence>.json` retains full mechanical path and paired `code_run` lists with source locators. The rendered block is itself audited. The cursor is marked shown only after the active context is appended to provider history, and committed at review end. Provider retries reuse the same active block; no new capture is performed for a retry. Same-review requests without new Task events or path changes receive a short unchanged line; follow concurrency can refresh just the newly visible interval. A root handoff routes to a root review even if the ordinary review has not consumed its event.

Offline replay command: `python -c "import sys; sys.path.insert(0, 'GenericAgent-main'); from method_discovery.cfs_v0_replay import main; main()"`. This reads only the archived EIS-v0 public events and historical WTV path samples. The replay output is a deterministic rendering approximation at those historical sample intervals, not a restored Supervisor session or model behavior. Fyne: 9 intervals, 23 path facts, 82 paired/unreturned `code_run` entries. Kitex: 8 intervals, 23 path facts, 48 entries. Fyne includes `app_test.go` and `test/testapp.go` path changes. Kitex event #118 falls in cursor interval 115→119; its `echo` script contains printed `go test ./...` text and remains one ordinary `code_run` command/result, with no derived validation label. Raw replay rows and SHA-256 are in `offline_replay/`.

Known mechanical limits: metadata fingerprints can miss an edit that restores the same sampled metadata; changes between samples can be missed; a concurrent workspace writer means a scan is not a frozen review snapshot. Symlinks and `.git` are excluded. Only call/result identities within one complete public event are paired, and unparseable results remain raw/unknown. The surface is excerpted; the full derived manifest and original public event remain available. A provider-ready input that was appended but whose transport later fails still counts as observed for the cursor; no successful model response is inferred.
