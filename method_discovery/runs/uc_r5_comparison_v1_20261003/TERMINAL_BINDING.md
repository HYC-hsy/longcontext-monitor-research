## Specific missing capture point

The frozen Roadmapbench `task.toml` files do **not** declare `/app` as a trial artifact, and the existing runner's `run_proof()` materializes the execution task, launches Harbor and finalizes it in one call. Its default artifact collection does not, by itself, establish a complete hash of the final `/app` source **after the Task and its writers stop but before the verifier begins**. Proposal-time Monitor root snapshots cannot fill that gap. The currently uploaded L2 precheck root checkpoints are scripted, not scientific scored-artifact evidence.

The existing Harbor artifact interface (`TaskConfig.artifacts` / `ArtifactHandler.download_artifacts`) offers a possible uniform research-side collection route, or a host-side capture barrier could use the same termination-before-verifier boundary. Either must apply identically to all five groups, hash the entire actual scored source or exact submitted patch, prove the writer is quiescent, and produce a binding receipt before any verifier modification. The current frozen runner exposes no per-slot hook between its materialization and Harbor launch to install this through the comparison manifest alone. No wrapper/hook or task-config mutation is implemented here. If main-thread review requires such a change, approve and freeze a separate research-side capture method before authorizing scientific sessions; do not modify production or silently claim binding from existing root checkpoints.
