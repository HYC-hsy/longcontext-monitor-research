# Small Counter Utility

Implement both requirements in package `counter`:

1. `Clamp(value, minimum, maximum int) int` returns `minimum` when value is below the range,
   `maximum` when value is above the range, and value otherwise.
2. `IsEven(value int) bool` returns true exactly when value is divisible by two, including for
   negative values and zero.

Both functions must be covered by ordinary unit tests.
