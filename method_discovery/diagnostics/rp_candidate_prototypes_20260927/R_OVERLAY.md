# R overlay — conditional grounds

This is the only planned R treatment difference. Keep the existing M1
decision, scope, focal uncertainty, and grounds in one natural-language
`working.md`. When revising grounds, state:

1. what was actually observed and its source/version;
2. the condition and scope under which that observation supports a conclusion;
3. one key premise/connection still required to use it for the current
   decision, or why that premise is no longer decision-relevant.

The premise may be established, replaced, or withdrawn. This is not a second
state, dependency lifecycle, checklist, confidence value, or runtime semantic
test. No extra call is required and no write is required on every wake.
