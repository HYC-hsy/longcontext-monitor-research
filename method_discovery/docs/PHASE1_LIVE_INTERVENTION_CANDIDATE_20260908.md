## 本轮变化

- agent.py：运行时提供发送回调时，intervene发送后返回普通工具结果，不结束run_review。模型可以继续工具调查并最终wait；不要求每轮发消息，不禁止完整审计。原有工具、同一history和自然记忆不变。
- runtime.py：发送立即进入已有异步输出通道，不等待审议结束。若正在处理completion，首条纠偏即回答其continue并消费当前提议；后续纠偏走普通中断，不重复发送结束决定。模型发送后不能allow旧完成提议。工具结果明确queued而非已采纳，实际回执仍由父进程写delivery_feedback.jsonl，模型可主动读取。
- loop.py：无工具回答不再收到“intervene必然结束审议”的旧说明，遵循当前模式；不把无工具回答当传输失败。
- exact相同消息仅在同次review内避免重复提交，不进行语义相似匹配、不禁止后续修正；跨review未强制去重，允许重新提醒。队列提交失败不标记已发送。
- runtime config `monitor_live_intervention=false` 可消融为旧终结式干预。启用时 provider CONTROL_ACTIONS 只有wait/allow_complete，避免压缩将一次发送误当作已经结束的完整审议。
