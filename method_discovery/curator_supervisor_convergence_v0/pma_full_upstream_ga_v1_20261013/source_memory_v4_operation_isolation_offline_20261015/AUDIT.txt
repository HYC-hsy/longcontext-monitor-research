What changed
------------
S2/R2 Phase 1 still makes one model request and receives its existing ordered
structured tool-call list. Each operation now copies the last committed bank,
executes and validates on that copy, then commits only that operation. A normal
argument/source/ID rejection discards that operation and allows later calls.
One reconcile/revise is an atomic unit across active entry, metadata, history,
index and coordination; separate delete/save are not inferred to be a revision.
An unexpected host integrity exception stops subsequent operations and blocks
the Phase 2 request, while previously committed operations remain in the bank.
No accepted provider request is replayed. No extra model call was added.

Phase summaries distinguish committed, partially_committed, all_rejected,
no_change, no_operations and host_failure. The retained `committed` boolean now
means at least one state-changing operation committed; it does NOT mean all
operations succeeded. committed_count, no_change_count, rejected_count and each
row's post-operation commit_version make partial state visible in Phase 2 and
the next Phase 1. Full before_bank/after_bank and raw errors remain audit-only;
the model view stays an explicit whitelist. `collateral_aborts` is retained for
old archive compatibility but is zero under this implementation.

The shared statement_type guidance is used in both the actual S2/R2 Phase 1
system and Pydantic-generated save/revise schemas. task_requirement requires
task_instruction provenance; tool_observation is a directly returned tool
observation, not an inferred effect; agent_report is attributed to Task;
inference remains an inference. knowledge/procedural describes memory use, not
claim type. A citation proves provenance only, not truth or entailment. Mixed
claims should split or be marked as inference. Test source, edit receipt and
old source do not by themselves prove current runtime behavior. Existing host
role constraints remain group-level, not per-reference; source roles are not
silently changed to pass validation.
