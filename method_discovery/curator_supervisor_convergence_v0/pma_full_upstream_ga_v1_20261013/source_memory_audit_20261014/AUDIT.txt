6. Deliberate limits and interpretation
The static screen is a new fixed-trajectory shadow comparison on two exposed
development cases, not a replay of the historical PMA internal state and not
counterfactual Task success. Prior Task actions may have been influenced by
historical PMA. Returned reminder is not a GA request delivery. U/S/R differ
in method prompt, bank formatting and S/R citation rules; this is not an
atomic transaction ablation. Valid source only proves that an excerpt was
visible, not that it supports a conclusion. An unresolved memory can still be
misused by free-form phase-2 synthesis. Equivalent old errors elsewhere and
derived conclusions are not automatically cascaded. BM25 is upstream, not a
semantic validator. Evidence character accounting excludes tokenizer-specific
cost; provider usage/inner attempts are unknown in future real runs. Here
all intercepted fake sends are counted, real Task/PMA/provider/evaluator,
training and scoring calls are 0. Actual future endpoint compatibility and
semantic quality remain unverified.
