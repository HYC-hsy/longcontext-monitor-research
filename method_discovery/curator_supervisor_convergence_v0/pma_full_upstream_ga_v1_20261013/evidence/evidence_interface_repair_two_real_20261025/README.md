## How to read the package

`INDEX.json` lists both slots. Each slot has `IDENTITY.json` and `INDEX.json`. The slot index maps every private source file SHA-256 and every original line SHA-256 to the corresponding redacted gzip file, its compressed/uncompressed hashes and each public line hash. These 31 compressed files per task contain all selected available visible sources: the six host streams (including actual role inputs/outputs, gap cycles, write receipts and errors), final memory with bound-source/revision/receipt data, trajectory, Task events, terminal and evaluation receipts. They are not summaries. Use `gzip -dc <file>.jsonl.gz` or the corresponding `.json.gz` file to read them.

Each slot also has `turn_audit/`: `cycles.jsonl` pairs actual maintenance/selection prompts, visible responses, operation reports and committed gap view; `task_turns.jsonl` pairs each Task request, response, action and later visible tool receipt; `reminders.jsonl` binds each delivered reminder to its Task request and following visible response; `evaluation.jsonl` exposes only preparation/test counts and reward. `turn_audit/INDEX.json` records the original source and public-byte hashes and exclusions. The legacy field name `review_and_stale_report` in the turn export denotes the recorded cycle report; this two-stage evidence method had **no reviewer or stale-state phase**. `evidence_write_report` is the authoritative accepted/partial/succeeded/failed write outcome.

The private originals retain unmodified source text and original citation coordinates. Public projections are reserialized and redacted; their byte hashes must not be mistaken for original HTTP or original private-file bytes. Known private profile values, endpoints, credentials and hidden-thinking fields were removed or replaced. Hidden test source, assertions, raw headers and private profiles were never selected. Some free-form visible text is redacted, so a public citation may no longer be independently character-revalidated; use the private source hash and bound receipt for that check. The raw originals remain local, not in Git.

The package was verified against both local originals: 62 compressed source files and all turn-audit files matched their index hashes and line maps; selected private source hashes matched; no local private-profile value remained in the exported content. Source files were not reconstructed from summaries. This is a two-task diagnostic, not evidence of statistical advantage over PMA or the prior gap variant.
