close remain the structured-state owner. Original Sentinel audit/revision,
progress, trapping, recovery, and textualization order remains in that
manager. episode.PoSEpisode maps one completed GA decision's ordered native
tool batch to one transition; it does not create a PMA agent or memory bank.

the adapter with the corresponding GA batch shape; role call order, committed
belief, recovery and scored state matched under fixed responses. Action
transport representation differs and is not claimed byte-identical.

The original prompts.react_prompt hybrid semantics — current observation,
belief_text, goal plus frontier-relevant world subgraph, active gap, frontier

upstream _frontier_relevant_world and FRONTIER_ACTION_SELECTION_CONTRACT.
Only LOCA-specific JSON thought/action, exactly-one-tool/claim_done,
unrelated Canvas example and redundant tool catalog are replaced by GA
native action/termination protocol. The authoritative tool definitions are
sent once as the provider's native tools payload. The original Task text and
current observation remain in the request. This is a prompt-envelope
adaptation, not evidence that Task decisions improve.

GA NativeClaudeSession.ask_stateless now preserves empty public content for
native tool-only responses; it never synthesizes a summary from a private
thinking block. Text <think>/<thinking> is separated like the existing
session path. The final requests.post-boundary fake test archives the actual

raw_v4/http_boundary_payload.json. It checks absent old backend history and
working-memory canaries; present Task/current observation/new instruction,
goal/gap and one native tools list. The fake native thinking canary is in
the response fixture but absent from the request/public content.

GA's new extrakeyinfo/_keyinfo is consumed with explicit source and one-use
lifetime into the current PoS request. The prior turn's fresh key_info is
carried in its actual next observation; old working memory is still
suppressed. Pre-call resumable correction is sent as a current runtime
instruction. pos_decision_context and bridge ownership are restored in a
generator finally, including error and close, so the same parent can run
PoS-on then off without residual PoS context.

The action batch contains call ID/name/original parameters/order and actual
status, never a duplicate result. Raw outcomes are logged separately before
PoS processing in *.host.jsonl and the PoS observation has one tool_results
receipt sequence. Unknown/unmounted tools are rejected observations, not
executed environment actions and not scored PoS transitions. A started tool
that raises is recorded as result-unknown, never replayed. A code_run
exit_code=null and process_state=still_running are preserved without claiming
command completion. No adapter result truncation threshold was added.

PoSEpisode stores completed GA decisions separately from original manager
transitions with valid progress in {0,1}; invalid progress is unscored, not
zero. The K=8 parameters and upstream recovery mathematics are unchanged.
One eight-tool batch remains one PoS update, not eight steps. Unknown online
success remains success_known=false/task_success=null, and a host legal
CURRENT_TASK_DONE is not evaluator success. Host terminal reason and core's
last actual transition.done are separate. No-tool completion creates no
terminal action. An active recovery at host termination remains the core's
last active recovery, not a fabricated recovery release.

The worker now fsyncs a case-bound *.result.json after finish/abort and
attempts a partial snapshot after command error/EOF. If the snapshot itself
fails it records missing, never saved. The bridge closes stdin and waits for
normal worker exit before forced termination; forced termination status is
separate. It does not resend commands after unknown acceptance/receipt.
Terminal auxiliary update failure is logged and cannot overwrite an already
observed host CURRENT_TASK_DONE; the independent host journal preserves the
tool result and terminal event. Any PoS auxiliary failure before Task terminal
still fails the run and never silently falls back to GA-only/PMA.
