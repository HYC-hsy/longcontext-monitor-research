# Simple predictive-memory variant

Based on `1272f883aea9e8ffb61fa78f7c610537f2b10f64`, for the full upstream-PMA GA adapter (`GA_PMA_UPSTREAM_ENABLED`), not the separate legacy `GA_PMA_ENABLED` path.

- P1 has one `memory_add(content)` tool. It sees the full saved bank without categories and saves information expected to be useful in the next 10 turns. No forced write and no automatic expiration, deduplication, edit or delete.
- Entries are physically stored in the existing knowledge list for persistence compatibility; the P1/P2 display is a flat bank. Legacy procedural entries are shown too. The old >50-item BM25 prefilter is disabled for this variant, so prompt size can grow without bound.
- There is no initial task-only call. After eight new eligible actor steps, P1 and P2 run together. Normal and parse-error actor steps count; provider-cancelled and completed events do not. The original task description is included alongside each batch. There is no inference for an incomplete terminal tail; the archive reports its count and attempt IDs. P2's original system instructions and parser remain, but its bank contents and cadence change.
- The GA bridge carries native visible text/tool-use blocks in order and separately the next actor-visible tool-result/text blocks. The order, boundaries and tool-use IDs are retained; objects require textual serialization. Provider reasoning blocks and synthetic reasoning-derived summaries are excluded. Where original blocks cannot be safely projected, the prompt states they are unavailable; it does not substitute a synthetic response. If previous framework history could contain a synthetic summary, its text is withheld conservatively. Existing session/task behavior remains unchanged.
- Original PMA catches phase errors, and an accepted timeout has an unknown outcome; a triggered batch does not guarantee either phase succeeded. The implementation does not automatically replay a batch.
- `tests/test_simple.py` includes seven focused offline checks. This sparse-workspace check uses a `shortuuid` substitute and isolates two classes with AST extraction. It is not a full GA/Harbor integration test. No real model or task evaluation was run.
