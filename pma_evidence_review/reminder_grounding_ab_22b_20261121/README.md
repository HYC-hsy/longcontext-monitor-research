## 首次启动前（零模型调用）

- 用 manifest 的 execution_base，及 source_archive（`pma_evidence_review/manager_response_capture_three_20261121`）和本机原件定位四个现场。核对首次真实请求的原始任务、轨迹、历史、工具定义、知识库快照和延续状态。公开投影可能不是出站字节；若必需内容已脱敏、状态缺失，或无法复原，不补猜、不用摘要替代，明确标出缺项并暂停。
- `prompt_sha256` 对归档首次请求的 prompt 原始字符串，`history_canonical_sha256` 和 `tools_canonical_sha256` 对对应公开投影 JSON（Python json.dumps(sort_keys=True, separators=(',', ':'), ensure_ascii=False)，UTF-8，无末尾换行）；`initial_read_content_sha256` 对首次成功 memory_read 回执 JSON 解码后的 content 字符串。同一冻结快照对两组相同；有更完整本机原件时另记私有原件哈希，不误称与公开投影字节相同。
- 每次都从该唤醒首次请求开始。第一条 `memory_read` 若由模型自然发起，返回独立的当时库副本；以历史第一次读库证明初始可见内容、顺序一致，不将历史回执预塞进输入。沿用真实 PMA 工具规则、恢复和结束判定。之后的工具回执只来自本次调用的隔离副本，读库反映本次写入，提醒进入隔离记录且不接任何真实 Task。不能用原轨迹同一唤醒里后续的模型输出或回执代跑，不能写生产库。
- 用模拟回复验证普通/补句分支、首请求除 system 单行外完全一致、隔离写入和重读、提醒队列不外送、无提醒与错误保留。锁定实际模型 claude-opus-5、温度 1、原提供方请求配置/上下文裁剪/重试与终止规则。给两组相同的每唤醒调用/时间上限，报计划总预算、实际配置和可见会话与日志位置，确认后再开始真实调用。若缺能力复刻，先报告；不通过更换模型或简化工具来凑结果。
