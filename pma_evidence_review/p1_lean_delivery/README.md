## 三原则怎么落实

- **完整性**：保留 PMA 原版首轮和后续的八项整理角度，保留事实、经历、GAP、内部状态及删除能力。仍区分实际观察/推断、计划/执行、未知/失败，保留范围条件和有用的测试缺口。
- **简洁性**：GAP 与事实、经历平级定义，不另写一套生命周期长文；准确性和维护原则统一说明。删除重复的更新解释、绑定算法、内部发布状态等模型不必操作的细节。没有把这些文字搬进工具描述。
- **自然性**：按“整理哪些内容、怎样保持准确与精简、工具怎么用”的顺序写，不让模型额外生成分类报告、理由、评分或审核结果。

## 保留的具体边界

- 重读日志或 checkpoint 不算另一次尝试；实际执行尚无结果时保留未知结果。
- 临时阻塞解决后仍保留原条件未解决的部分；只关闭已解决或不再适用的事项。
- 经历保存可复用的尝试和结果，不不断追加全任务流水账；没有有用变化则不重写。
- 编号只用于更新已有同类条目；证据仍可选，保留必要的引文数组/XML格式说明。定位与匹配实现没有改动。
