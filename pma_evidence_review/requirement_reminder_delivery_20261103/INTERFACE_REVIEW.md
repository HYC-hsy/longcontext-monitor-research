P2 accepts fully shown M, TASK, STATUS and returned session P2H. Labels are stable across flat/requirement views within one frozen request, not between P1 and P2 or later requests. The legacy `memory_id` host call path remains compatible and rejects ambiguous IDs. Passing both fields fails.

Initial catalogues and model browse records omit internal memory_id. Complete returned history directory entries retain original grants; projection only removes their redundant internal identifier. Typed entry history reads remain captured in later frozen input coverage.
