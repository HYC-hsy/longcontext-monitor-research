# Four-turn first-use PMA: five real tasks

This is a redacted visible projection of five completed real Task episodes, not raw provider HTTP bytes. The fixed execution code is `d0e6965cf7c0e88d3c274ab749c7ac23fe2589ea`; dataset `2fd12b88aafdd04a52c298e3940bcb189f9766d6`; Harbor `459ff6ec99417589b7f679d14ddf3b3f0ae4f1dc`.

`PMA_FOUR_TURN_FIVE_REAL_20261112.zip` includes visible Task/PMA traces, requests and responses, tool receipts, final banks, native evaluation summaries, configuration/identity, focused offline checks, runner logs, and cleanup records. `*.index.json` lists every member's original and public SHA-256/size and the ZIP SHA-256. `*.facts.json` and `*.wake_index.json` provide mechanical navigation; the complete projected records remain in the ZIP.

The task agent used claude-opus-4-8; the unified manager used the claude-opus-5 profile. Task total turns and total runtime were uncapped; verifier limits remained official. Five episodes ran serially with new run IDs and independent banks. All five completed their native evaluation and confirmed owned-resource cleanup. They did not produce a reminder delivered to the Task agent.

The public copy excludes credentials, authentication headers, private endpoints/profiles, provider-private thinking/signatures, hidden verifier content, source bundles and private tracebacks. Private originals remain on the local host. Redaction occurs only in this public copy; the original run inputs were not changed. Public text from the manager is not a substitute for private reasoning. Token totals in the facts file are Task-side reported usage, not full Task+PMA cost; PMA usage and actual provider request attempts were not reliably available and remain unknown.

The focused offline suite had 264 passing and two failing checks. The same two failures occurred on the unmodified parent in the same environment: LiteLLM's installed `AsyncHTTPHandler(transport=...)` mismatch and a Python-3.13-specific hardcoded AST hash. These were retained, not edited away or represented as all tests passing.

See [OBSERVATIONS.md](OBSERVATIONS.md) for outcome and limited behavioral observations. One episode per task does not establish a stable benefit or a causal effect of the prompt wording.
